## things I've learned from breaking stuff 🪦

- 🧱 **C** — taught me that computers hate me personally and it's mutual
- 🐍 **Python** — same pain, but at least the error messages are readable
- ☕ **Java** — wrote 200 lines to do what Python does in 5. still processing why
- 🌐 **HTML / CSS / JS** — the holy trinity of "why is this div doing that"
- 🟢 **Node.js** — backend developer origin story. it's just JavaScript but angrier.
- 🚂 **Express** — so minimal it makes you do all the work. and then blames you for it.
- 🏗️ **NestJS** — wanted a backend framework. got a philosophy lecture instead.
- 🗄️ **MySQL** — I know exactly which query will nuke the database. I still run it.
- 🧩 **DSA** — I know the theory. interviewers know I know the theory. mutual suffering.
- ⚛️ **React** — I don't know why I used it. it doesn't know why it re-rendered 47 times.
- 🌊 **GSAP** — made animations so smooth people thought it was a video. it was not a video.
- 🧊 **Three.js** — put a 3D cube on a webpage. my laptop fan has never forgiven me.
- 🧜 **Mermaid.js** — turns text into diagrams. the only time my code actually explained itself.
- 🔁 **REST APIs** — the art of sending JSON back and forth and calling it a career.
- 🌐 **WebSockets** — real-time communication. real-time anxiety.
- 🔐 **JWT / Auth** — spent 3 days on authentication. users still find a way in.
- 🐙 **Git** — I commit. I push. I pray. sometimes I force push and pretend nothing happened.
- 🕸️ **LangChain / LangGraph** — building agents smarter than me. they still argue back.
- 👁️ **YOLO** — trained a model to see the world. it still can't find my missing semicolons.
- ⚙️ **n8n** — automating everything so I can be lazy at a much higher level
- 🧬 **GenAI** — used it so much I now ask AI for permission before making life decisions
- 🤖 **AI Agents** — built systems that think for themselves. deeply regret it.
- 🔍 **Search Algorithms** — hill climbing, simulated annealing, beam search. suffering at every local minima.
- ☁️ **Cloud** — learning to put my problems on someone else's server
- 📊 **Dashboards** — built more dashboards than launched products. it shows.
- 🎮 **Game Dev** — started a game. still "in development". since forever.
